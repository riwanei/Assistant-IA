# Réseaux — notions essentielles
Un routeur relie plusieurs réseaux IP et choisit une route pour les paquets.
Une adresse IP identifie une interface dans un réseau.
Le DNS associe des noms de domaine à des enregistrements, notamment des adresses IP.
DHCP attribue automatiquement une configuration réseau aux clients.
TCP fournit un transport fiable et ordonné ; UDP transmet des datagrammes sans cette garantie.
